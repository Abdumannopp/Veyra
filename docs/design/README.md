12 ta sahifa alohida, mustaqil SVG vektor fayl sifatida qayta chizildi. Matnlar, kartalar, chiziqlar, diagrammalar, tugmalar va ikonlar SVG elementlari; ular Figma, Illustrator yoki Inkscape’da tahrirlanadi.

## Import
- Figma: SVG faylni canvas’ga drag-and-drop qiling yoki File → Place image.
- Illustrator / Inkscape: SVG faylni bevosita oching.
- Vektorlar 1672×941 artboard o‘lchamida; istalgan o‘lchamga sifat yo‘qotmasdan kattalashtiriladi.

Eslatma: bular avvalgi raster konseptlar asosida qayta chizilgan, tahrirlanadigan vektor maketlar. Ular asl PNG screenshotning pixel-perfect tracing nusxasi ham, ishlaydigan frontend kodi ham emas.
